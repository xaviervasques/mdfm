# mdfm: the model code

The measured body of the design (docs/MFM_DESIGN_2026-09-24.md, sections 1 to 4) and its
sensor kernels. Runs in the mdfm conda environment (env/README.md). Tests: from the tree root,

    <conda>/envs/mdfm/python.exe -m pytest -q -p no:cacheprovider tests

(-p no:cacheprovider keeps pytest from writing a cache folder into the tree.)

- stage2.freeze: the groups of config.STAGE2_FREEZE_GROUPS (decoder, body_heads) that phase C leaves untrained, out of the optimizer, their EMA kept at the start's (train/loop.py, freeze_parameters); () by default, both in configs/stage2_s2b.yaml.
- stage2.window_cap_per_person: the cap of each stage-2 unit's share of the phase C windows, per training person of the unit, the windows it removes refilled from the replay (data/sampler.py, enforce_window_caps); 0.0 (off) by default, 0.00089 in configs/stage2_s2b.yaml.
- stage2.redraws: how many times in a row the phase C sampler draws again a plan or a step that the caps leave empty (data/sampler.py, redraws); 0 by default, 8 in configs/stage2_s2b.yaml.
